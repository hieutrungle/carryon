## Risks and early signs
- **Blackwell vs. cluster drivers:** cleared: A40 and A100 nodes run 580.126.20, local runs 595.99.02. The pinned wheels are CUDA 13.0 (decision 002), which needs ≥ 580; one image serves all three.
- **Apptainer-built SIF under SingularityCE 4.4:** cleared with a CUDA 12.8.1 base image on an A40 (2026-10-25). Re-check with the full CUDA 13.0 image in M0.9.
- **vLLM support for Qwen3.5 hybrid layers:** if rollouts fail or drift in M0.13, pin the last version that worked or promote Gemma 4 E4B (plan risk table).
- **Apptainer build permissions:** build locally with `sudo`; if that is not possible, build from a Docker image pushed to a registry and `singularity pull` it on a FASTER compute node.
- **Trajectory log size:** a 4 × 4,096-token episode is about 209 kB of JSON (0.9 ms to parse), so a GRPO run that logs every rollout could reach several GB. M0.4 gzips the JSONL when a run finishes (plain JSONL while running, so a killed job leaves readable lines). Whether training logs every step or every k-th step in full becomes a trainer config field in M4.
- **Scratch file count:** about 680k files free. HF caches create many small files; clean up old projects before M0.10, and prefer the single-file `.sif` over a venv on FASTER.
