## Risks and early signs
- **Blackwell vs. cluster drivers:** a CUDA 12.8 image needs driver ≥ 570 on FASTER GPU nodes; if they are older, build a second image tag on CUDA 12.4 for the cluster and record it in decision 002.
- **vLLM support for Qwen3.5 hybrid layers:** if rollouts fail or drift in M0.13, pin the last version that worked or promote Gemma 4 E4B (plan risk table).
- **Apptainer build permissions:** if neither machine allows `--fakeroot`, build from a Docker image pushed to a registry and `apptainer pull` it.
- **Scratch quota / file counts:** HF caches create many small files; check `showquota` before M0.10.
